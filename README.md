# XQLT candidate reproducibility in fibrotic human lungs

Data and analysis code accompanying the manuscript:

**Cross-cohort reproducibility and cellular context of network-selected Xiao Qing Long Tang candidates in fibrotic human lungs**

Authors: Lu Hao, Bi Chen, Lei Ji and Di Hao.

## Download

The versioned release asset `Supplemental_Data_S1_v4.zip` contains the supplementary data and analysis code. Download that named asset from the release page and extract the complete archive, preserving its directory structure. The individual workflow directories contain the relevant scripts, inputs and documentation.

## Contents

- Recovered original network input tables and selection scripts.
- Processed inputs and complete results for the original human lung cohorts.
- Additional GSE150910 cohort analyses and sensitivity analyses.
- Competitive comparisons with historical target sets and transcriptome backgrounds.
- Public constituent-target assay records and provenance tables.
- Figure source files and analysis scripts.

## Scope

This compact package does not contain the molecular-dynamics trajectory archives or the complete docking job archive. These materials must be described and shared separately; the release must not be cited as covering all historical structural calculations.

`SHA256SUMS.txt` records the SHA-256 checksum of the release asset. Public source datasets and third-party materials retain their original attribution and reuse terms.
